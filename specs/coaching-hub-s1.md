# コーチングの最初の画面を「作る 3 つ＋最近の保存＋ライブラリ」に（S1 性格づけ。2026-11-07）

分析 PDF「ALFA_FOOTBALL_スマホ版の骨組みと雰囲気のUI案_2026-11-07」（生成元 ~/.claude/alfa-verify-tools/navres-report/design.md）§4 の **S1（今のまま＋性格づけ）** を実装する。オーナーの決定（2026-11-07）：**骨組みは S1 で止める。色・雰囲気は今の青のまま（V1）。設定の「外観」は作らない。** 前の PDF（練習メニュー作成の改善案、2026-11-06）の「案 D コーチング目次のタイル化」は取り下げ、本仕様に置き換える。

- 問題：下部タブ「コーチング」と「チーム」を押すと、どちらも同じ型の目次（白いカードの行リスト／タイル）が出て、「チーム＝時間」「コーチング＝作る物」の性格の違いが見えない。コーチングは 4 行＋最近の保存で下に約 300px の空きが出る。
- 直し方：コーチングの最初の画面だけを「作る 3 つ（正方形）→ 最近の保存（6 件）→ ライブラリ（件数つき）」の 3 段にする。チーム・その他・下部タブ・ヘッダー・各画面の中身は変えない。
- 触るもの：`components/CoachingHub.tsx`、`app/globals.css` の 1 区画（基底。§2）。仕様の追記：`specs/mobile-redesign.md` §1-3 と §8 #14、`CLAUDE.md` §6・§9。
- PC（≥1024px）は変えない。`CoachingHub` は PC 幅では描画されず（`usePc()` で `home` に戻す）、`.chubapp` 配下の CSS は PC に到達しないので PC reset も不要。`@media` は増やさない（9 本のまま）。

## §6 実装時の判断（実装・レビューで追記）

1. **正方形の間隔は 12px**（PDF のモックは 8px）。CLAUDE.md §5「カード間 12」とチームの目次のタイル（gap 12）に合わせた。幅は 390 で 111.3px、高さ 104px（実測。p42。丸の地があった最初の実装では 124px）。
2. **件数の数字は 17px**（`.stat .v` の 22px ではない）。独立した指標タイルではなく、ライブラリの行に付く件数なので 5 段の中に収めた。数字 3 つは §8 #16（1 画面 3 つまで）の範囲内。
3. **mobile-redesign §8 #14 の例外 2** を足した（§3-1）。PDF §4-7 の「決まりとの衝突なし」は誤りだったので、本仕様で訂正する。
4. **正方形の名前「セットプレー」**：画面名「セットプレーデザイン」は 10 文字×14px＝140px で 111px に入らない。画面のヘッダー・最近の保存のラベル（「セットプレー ・ 11/2 22:34」）は今のまま。
5. **0 件のとき**は説明に件数を付けず、帯も描かない（「0」を 3 つ並べない。実測 p42 `m_coaching_empty`）。空の状態の文言は今のまま。
6. **最近の保存 6 件**は上限。デモデータは戦術 2・練習 1・セットプレー 1 の計 4 件なので、画面では 4 行（6 件の上限はデモでは見えない）。
7. **行の下線の重なり**：`.mrowcard` の中で `MenuRow` の後ろに帯を置くと `.mrow:last-child` が効かず下線が残るので、`.mrowcard:has(.chub-cnt) .mrow { border-bottom: 0 }` で消した（実測で行の下線 0px・帯の上線 1px）。
8. **検証スクリプトの選択子**：p41 までの `clickText(page, ".mrow", "^練習メニュー")` は `.chub-sq` に変わる。p42 は `.chub-sq, .mrow` の両方を探す（変更前後で同じスクリプトを使うため）。
10. **レビュー A（撮影）・B（コード差分）の指摘**：A-1/B-1 丸の青い地が #15 に当たる（両方が指摘）→ 丸を外した（§3-1-b。CSS 2 規則）。A-2/B-2 中央揃えが #13 に当たる → #14 の例外 2 に 1 文足した（§3-1-c）。
11. **直さなかった指摘**：A-3 ライブラリの行の「N 件」と帯の内訳が重なって見える（3 等分の数字の帯は AI のサインになりうる）→ 今のまま（§6-2 の判断。数字は 3 つまでの範囲内。気になるなら行の説明から「N 件」を外す）。A-4 保存 0 件の空の状態（`.chubapp .empty-msg`）が 13px・上下 40px・2 文目が 1 字だけ折り返す → 仕様 §1-4 で「今のまま」とした既存の見た目で、`.empty-msg` は多画面共用なので本作業では触らない（直すなら `.chubapp` に限定して 14px・余白 16px にする別作業）。次の一手は真上の正方形 3 つが担うのでボタンは足さない。
9. **変更前後の画素差分（p42。丸を外す前の撮影。外した後は §4-1 の寸法だけ撮り直した）**：PC 4 画面（ホーム・戦術ボード・ライブラリ・チーム）と選手 3 画面（ホーム・チーム・プロフィール）、スマホの戦術ボード・練習メニュー・セットプレー・ライブラリを比べた。差が出たのは「デモデータの時刻（22:29 → 22:34。シードした時刻からの相対値）」「ホームの『あと N 時間』」「背景の薄い放射状の描画ノイズ（選手のチーム・プロフィール、セットプレー）」だけで、どれも本変更の CSS（`.chubapp` 配下・`.chub-*`）が届かない場所。差分 0 の画面：PC 戦術ボード・PC チーム・選手ホーム・スマホ戦術ボード・練習メニュー。
