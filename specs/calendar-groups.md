# カレンダーのグループ（対象）機能 仕様

作成：2026-09-15／設計：fable5／実装：sonnet5／レビュー：opus5
対象：チーム運営＞カレンダー（スマホ・PC 両方。PC のカレンダータブ・予定フォーム・予定詳細も同じ部品なので同時に対応する）

## 0. ユーザー指示（原文の要点）

1. カレンダーに同じ日の予定を複数入れられるようにする。
2. 予定を入れるときに「1年生」「2年生」「Aチーム」「Bチーム」のようなグループを指定できるようにする。
3. カレンダーを見るときにグループを選んで、そのグループだけの予定／全部の予定を切り替えられるようにする。
4. 全選手が対象の予定は、どのグループを選んでいても表示する。
5. A〜E チームがあって A・B・C が対象の予定もあるので、複数選択できるようにする。

## 1. データ

```ts
/** チームのグループ（学年・A/Bチームなど）。順序は配列順 */
export interface TeamGroup {
  id: string;     // nid("grp")
  label: string;  // 例「Aチーム」「2年生」
}

export interface TeamData {
  // 既存のまま…
  /** グループのマスタ。未定義＝グループなし */
  groups?: TeamGroup[];
}

export interface TeamEvent {
  // 既存のまま…
  /** 対象グループ。未定義または空＝全員対象 */
  groupIds?: string[];
}
```

- `lib/calendarUtils.ts` にヘルパーを追加：
  - `isAllTargets(e: TeamEvent): boolean` → `!e.groupIds || e.groupIds.length === 0`
  - `eventTargetsGroup(e: TeamEvent, groupId: string | null): boolean` → `groupId == null || isAllTargets(e) || e.groupIds!.includes(groupId)`
  - `targetLabel(e: TeamEvent, groups: TeamGroup[]): string` → 全員対象なら「全員」、それ以外はグループ名を「・」で連結（削除済み ID は無視。全部削除済みなら「全員」）
- `TeamProvider`：`groups: TeamGroup[]`（`team.groups ?? []`）、`addGroup(label): string`、`updateGroup(g)`、`removeGroup(id)`（削除時は全予定の `groupIds` から外す）。カテゴリ（`addCategory` 等）と同じ作法。
- `lib/storage.ts` の読み込み正規化で `groups` が配列でなければ `[]` にする。
- 旧データ互換：`groupIds` 未定義＝全員対象。保存形式は追加項目のみ。
- デモ用サンプル（`TeamProvider` の初期データ）に、グループ「Aチーム」「Bチーム」「低学年」「高学年」を入れ、サンプル予定のうち「練習試合」を Aチーム対象、「全体練習」は全員対象、1件を「低学年」対象にする（機能が最初から見えるように）。

## 2. 予定フォーム（追加・編集）

- 「カテゴリ」の下に **「対象」** の欄を追加。チップの横並び（折り返し）：
  - 先頭「全員」：どのグループも選んでいないときに選択状態。タップで選択中のグループを全部外す。
  - 各グループ：**複数選択**（タップでトグル。選択中は `--accent-tint` 地＋`--accent` 枠・文字）。
  - 末尾「＋ 管理」：グループ管理シートを開く（下記）。
- 保存：選択が0なら `groupIds: undefined`、あれば `groupIds: [...]`。繰り返し作成（`addEventWithRecurrence`）・「以降すべて」更新（`updateSeriesFollowing`）にも `groupIds` を渡す。
- 編集時は既存の `groupIds` を初期選択にする。
- グループ管理シート（`SheetState` に `{ type: "groups" }`）：カテゴリ管理シート（`{type:"categories"}`）と同じ構造（追加・改名・削除。削除は確認ダイアログ）。PC ペインの「戻る」は予定フォームへ戻る（`paneBack` に追加）。
- グループが1つも無いときは「対象」欄に「全員」と「＋ 管理」だけを出す。

## 3. カレンダーの絞り込み

- カレンダータブ（`CalendarTab`）の月送りの上に **絞り込みの行**（`.calfilter`。横スクロール可のチップ）：「すべて」＋各グループ（単一選択）。グループが無ければ行ごと出さない。
- 選択状態は `Inner` の state（`calGroup: string | null`）で持ち、タブを跨いで保持。`localStorage` の `soccer_tactics_calgroup_v1` にも保存して次回も同じ絞り込みで開く（存在しないグループ ID なら「すべて」に戻す）。
- 絞り込みの適用先（すべて `eventTargetsGroup(e, calGroup)` で判定）：
  - 月表示のマス（点・タイトル・「＋n件」）
  - リスト表示
  - スマホの月表示下「今日からの予定／この月の予定」
  - 日別シート（`{type:"day"}`）の一覧
  - 凡例（その月に出るカテゴリ）
- **全員対象の予定はどのグループを選んでも表示される**（ヘルパーの定義どおり）。複数グループ対象の予定は、そのどれを選んでも表示される。
- 絞り込み中は行の右端に「Aチームの予定と全員の予定を表示中」のような1行の補助文（12px `--mut`）を出す。
- ホーム（次の予定）・出欠・通知はこの絞り込みの対象外（変更しない）。

## 4. 同じ日に複数の予定

- 月表示のマスをタップしたとき：その日に予定が **1件以上あれば常に日別シート**（一覧＋「＋ この日に予定を追加」）を開く（現状は1件のときだけ詳細へ直行）。予定が無い日は現状どおり日別シート（追加ボタンあり）。
- 日別シートの一覧はカードをタップで詳細へ（現状どおり）。
- 月表示のマスの点は最大3つ＋4件以上は「+n」を小さく（12px 未満は禁止なので、点の右に 12px の「+2」）。

## 5. 対象の表示（バッジ）

- 予定カード（`EventCard`）、日別シートのカード、リスト表示の行（`.agbar`）、スマホ月表示下の行、予定詳細（`eventView`）に **対象バッジ** `.evgroups` を出す：`targetLabel()` の文字。「全員」は薄い地（`--surface-low`＋`--mut`）、グループ指定は `--accent-tint` 地＋`--accent` 文字。長い場合は1行で省略（`text-overflow: ellipsis`、詳細では全文）。
- 予定詳細（`eventView`）には「対象」行を追加（「全員」または「Aチーム・Bチーム・Cチーム」）。

## 6. CSS

- 新規ルールは基底に書く。`.calfilter`（横スクロール、`.mseg` と同じチップ文法：非選択＝白地＋1px `--outline`＋`--ink`、選択＝`--accent-tint`＋`--accent`、高さ36px、12px 未満禁止）、`.grouppick`（`.catpick`/`.evcatchip` と同じ見た目で複数選択の選択状態）、`.evgroups`。
- `@media` は9本のまま。PC は同じ部品を使うので、PC ブロックで見た目が崩れないか確認（必要なら2つ目の PC ブロック末尾の「mobile-redesign PC reset」に追記）。v1 §8（絵文字なし・新規 hex なし・44px タップ領域）を守る。

## 7. 受け入れ基準

1. 予定フォームで「対象」を複数選択でき、保存・再表示で保持される。「全員」で保存すると `groupIds` が無い。
2. カレンダーの絞り込みで「Aチーム」を選ぶと、Aチーム対象の予定と全員対象の予定だけが月表示・リスト表示・日別シート・今日からの予定に出る。「すべて」で全件。
3. A・B・C 対象の予定は A でも B でも C でも表示され、D・E では表示されない。
4. 同じ日に複数の予定を追加でき、マスのタップで一覧（日別シート）が開く。
5. 予定カード・詳細に対象バッジが出る。グループ管理で改名・削除ができ、削除したグループは予定から外れる。
6. `npx tsc --noEmit` 成功、`@media` 9本、スマホ全画面ではみ出しゼロ、PC のカレンダー以外の画面は変更前と一致（動的差分を除く）。

## 8. 検証手段

- 開発サーバー http://localhost:3000（起動済み。落ちていたら `(nohup npm run dev > /tmp/alfa_dev.log 2>&1 &)`）。`next build` 禁止。
- `scratchpad/tools/mobile_audit.js <outdir>`、`pc_baseline.js <outdir>`＋`compare.py diff pc_base <outdir> <diffdir>`。
- 動作シナリオ（puppeteer で自動化して報告）：①グループ管理で「Cチーム」「Dチーム」を追加 ②同じ日に「全体練習（全員）」「A・B 合同練習（A・B）」「C 練習（C）」の3件を作成 ③絞り込み「Aチーム」で 全体練習・A・B 合同練習 の2件だけ、「Cチーム」で 全体練習・C 練習 の2件だけ、「Dチーム」で 全体練習 だけ、「すべて」で3件 ④日別シートに3件並ぶ ⑤予定詳細の「対象」が正しい ⑥「Bチーム」を削除すると「A・B 合同練習」の対象が「Aチーム」だけになる。

## 9. 今回やらないこと（次の段階）

- 選手とグループの所属（`Player.groupIds`）と、ホーム／ウィジェットでの「自分の予定」の自動絞り込み。
- 出欠・通知のグループ対応。
