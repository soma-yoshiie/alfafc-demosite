## 1. ピッチの部品（`MiniPitch.tsx`）

### 1-1 幾何

- 単位は m。ピッチ 68×105（縦向き、上が敵陣）、まわりの余白 3。全面の viewBox は `-3 -3 74 111`、敵陣のハーフは `-3 -3 74 57`（ハーフウェーラインの 1.5m 下まで）。
- 入れ物 `.npitch`：`position:relative; width:100%; aspect-ratio: 74 / 111`（`.npitch.half` は `74 / 57`）、地は `var(--grass-b)` の 1 色（グラデーション・縞・影は無し）、角丸 `var(--r-lg)`（今と同じ 10px。ノートの画面のカードと同じ値にそろえる）、`overflow:hidden`。
- 保存の座標（x 0〜100 左→右、y 0 自陣〜100 敵陣）は線の中のピッチに写す：m では `X = x × 0.68`、`Y = (100 − y) × 1.05`。入れ物の中の % では `left = (3 + 0.68x) / 74 × 100`、`top = (3 + 1.05(100 − y)) / VH × 100`（VH は全面 111、ハーフ 57）。
- 指の位置から座標へは逆に写す：`xm = (clientX − left) / width × 74 − 3`、`ym = (clientY − top) / height × VH − 3`、`x = clamp(xm / 0.68, 2, 98)`、`y = clamp(100 − ym / 1.05, 2, 98)`（丸める範囲は今と同じ 2〜98）。
- この 2 つの写し方は関数にして export する（`fieldPct(x, y, view)`・`pointerToField(e, rect, view)`。後のまとまりで使う）。

### 1-2 線（マーキング）

1 枚の SVG（`svg.npsvg`、入れ物いっぱい、viewBox は上のとおり）の中のグループ `g.npmk` に描く。`fill:none; stroke: rgba(255,255,255,.78); stroke-width: 0.31`（幅 358px のとき約 1.5px）。

- 外枠 `rect(0,0,68,105)`、ハーフウェーライン `y=52.5`、センターサークル 半径 9.15、センタースポット。
- 両側に：ペナルティエリア（幅 40.32×奥行 16.5）、ゴールエリア（18.32×5.5）、ペナルティスポット（ゴールラインから 11）、ペナルティアーク（スポット中心・半径 9.15 のうちエリアの外に出る弧。端点は x = 34 ± 7.312）、ゴール（幅 7.32×奥行 2、ゴールラインの外側）。
- 四隅にコーナーアーク（半径 1）。
- スポットは塗りの小さな丸（半径 0.35、塗りは線と同じ色）。
- ハーフのときは、下側の物は viewBox の外になるだけ（描き分けない）。

### 1-3 軌道（線）

同じ SVG の `g.nplines` に、m の座標で描く。色は白（`tone="staff"` のときは §1-6）。影（`drop-shadow`）は付けない。

| 種類 | 描き方 |
|---|---|
| パス | 破線（`stroke-dasharray: 1.45 1.05`）、太さ 0.45 |
| ドリブル | 波線（`lib/drillDraw.ts` の `wavy(path, 0.85, 3.3)` を m に直した点列に掛ける。端は振れ幅 0）、太さ 0.45 |
| 旧データのシュートの線（`kind:"shot"`） | 実線、太さ 0.66（表示だけ。今も描けない） |
| 矢じり | 終点に塗りの三角（長さ 2.3・半幅 1.15）。向きは元の軌道の最後の 2 点から |
| 失敗（`success === false`） | グループの不透明度 0.6、終点に赤い輪（半径 1.45、`#ff5b6e`、太さ 0.42。今と同じ色） |

ノートの線は、練習メニュー・戦術ボードと同じ約束（ドリブル＝波線、パス＝破線）にそろえる。水色の点線（`#4fc3f7`）はやめる。

### 1-5 陣形（`FormationPitch`）

- props：`{ ownFormation, ownPositionIndex, onPickPosition?, oppFormation?, showOpp? }`。
- `showOpp` が偽（既定）：自分のチームだけを、`buildSlots()` の座標のままピッチ全面に置く（今は自陣側に 0.5 倍で縮めている）。相手は描かない。
- `showOpp` が真：今と同じ縮め方で両チームを置く（自分 `y × 0.5`、相手 `x → 100 − x`・`y → 100 − y × 0.46`）。
- 札 `.nptok`：30×30px の丸、白地・文字 `var(--ink)`・12px・700・`letter-spacing:-0.02em`（RWB・LWB が丸に収まるように）。自分のチーム `.own` は `onPickPosition` があるとき `button`（`aria-pressed`）。選んだ位置 `.sel` は地 `var(--accent)`・白文字・白の輪 2.5px（`box-shadow: 0 0 0 2.5px #fff`）。相手 `.opp` は輪郭だけ（枠 1.5px 白、地は透明、文字は白、押せない）。
- スマホの当たりは 44px（`body:has(.mhead) .noteapp .nptok.own::before { inset: -7px }`）。PC は 30px のまま。
- 左上に「敵陣 ↑」（12px・白 70%）。プレーのピッチにも同じ位置に出す。
- クラス名を `.mtok` から `.nptok` に変える理由：PC ブロックに `.noteapp .mtok` を 10px 台にする一覧があり、PC ブロックを編集せずに 12px を保つため。`.mtok` の基底の規則は消す（PC ブロックの中の `.noteapp .mtok` は効かない選択子として残る。PC ブロックは編集しない）。

### 1-6 プレーのピッチ（`PlayAreaPitch`）

- props は今のものに `view?: "full" | "half"`（既定 full）と `tone?: "player" | "staff"`（既定 player）を足す。
- 操作は今と同じ（点の道具＝押して離した所に置く、軌道の道具＝なぞる。閲覧では `onPointClick` があるときシュートの点だけ押せる）。
- 指の動き：軌道の道具のときは `touch-action:none`（今と同じ）。点の道具のときは `touch-action: pan-y`（ピッチが画面の大半を占めるので、点の道具の間は縦にスクロールできるようにする）。`pointercancel` で描きかけを捨てる。
- ハーフ：ハーフウェーラインより自陣側の印は入れ物の外になり見えない（消えない）。
- `tone="staff"`（スタッフの図）：線は青（`var(--accent)`）に白いフチ（同じ線を白・太さ 0.95 で下に敷く）。受けたの輪は青に白いフチ（`box-shadow: 0 0 0 1.5px #fff`）。シュートは黄のまま、枠を青に白いフチ。矢じりも青に白いフチ。（オーナー決定 12：「緑の地で青に白いフチ。黄はシュートだけ」）
