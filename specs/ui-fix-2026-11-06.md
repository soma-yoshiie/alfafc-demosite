## §1 チャット：自分の吹き出しが開いた直後だけ水色になる

**現状**：ホームのお知らせ・通知からスレッドを開くと、その吹き出しまでスクロールして 1.5 秒「光らせる」（`home-chat-groups-roster.md` §2-6。`ChatThread.tsx` の `focusId` → `.flash`）。`app/globals.css` の「ホームのお知らせ・通知から開いた吹き出しを 1.5 秒ほど --accent-tint で光らせる（自分の発言も同じ）」の規則で、`.chatrow.mine.flash .chatbubble` の地を `--accent-tint`・文字を `--ink` にしているため、**自分の青い吹き出しが水色に変わってから青に戻る**。お知らせは多くがスタッフ自身の発言なので、スタッフには毎回この「色が変わる」が見える。

**直し方**（CSS だけ）：

- その規則を `.chatrow.flash:not(.mine) .chatbubble { background: var(--accent-tint); color: var(--ink); }` に変え、`.chatrow.mine.flash .chatbubble` のセレクタを消す。自分の吹き出しは青のまま。
- 「どの発言か」の目印は、既にある輪郭の規則（`.chatrow.flash .chatbubble, .chatrow.menuon .chatbubble { outline: 2px solid var(--accent); outline-offset: 2px; }`）に任せる。青い吹き出しの 2px 外側に 2px の青い輪＝白い隙間を挟んだ輪になるので、青地でも見える。
- 相手の吹き出し（灰 `--surface`）は今までどおり水色＋輪郭。スクロール位置・1.5 秒の長さ・`focusId` の仕組みは変えない。
- 規則のコメントを「自分の発言は青のまま、輪郭だけ」に直す。

## §2 予定を追加（スマホ）：横振れと「種類の管理」の潰れ

.teamapp:has(.mhead) .sheetBody { overflow-x: hidden; }

  flex: 0 0 auto;
  min-height: auto;
  overflow-y: visible;

- `.catpick` は折り返して 2 段（練習／試合／遠征・合宿／保護者会／＋ 種類を追加）。右端のフェード（`.fbar, .mseg, …, .catpick` の `mask-image`）は折り返すと 2 段目の右端を消すので外す。

## §5 戦術ボード（スマホ）：道具列を横スクロールにしない

**現状**（390×844・スタッフ）：

- 編集：`.fbar` に 8 個（フォーメーション変更 251px／新規／整列／＋相手／ペン／図形／ハーフ／アニメ）で scrollWidth 894 › 390。右の 4 つは横にスクロールしないと出ない。
- アニメ：6 個（ペン／図形／ハーフ／ルート表示／描き込み／残像）で 596 › 390。
- ヘッダー右の「…」（`Header.tsx` の `MobileHeaderMore`）には既に「戦術アニメ」「ライブラリ」がある。
- ピッチは 302×540（min(64vh, 540)）で欠けていない。道具列を 2 段に増やす直し方は取らない（ピッチが主体。1 段のまま）。

**直し方**：道具列は「よく使う切り替え」だけ残し、残りはヘッダーの「…」の縦の一覧へ。

  mask-image: none;
  -webkit-mask-image: none;

- 残る幅：フォーメーション約 100px＋ペン 76＋図形 76＋間 7×2 ＝ 約 266px。360 幅（左右 14px で 332px）でも 1 段。`.fbar` の `overflow-x: auto` は残してよい（収まるのでスクロールしない）。

- ペン ON の `.fbarpen`、図形 ON の `.fbarshapes` は今までどおり道具列の下に出る。

### 5-2 ヘッダーの「…」（`Header.tsx` のスマホ分岐、`!isSp` のとき）

`MobileHeaderMore` の項目を、ボードのモードで出し分ける。上から「操作 → 表示の切り替え → 移動」。

| モード | 項目（アイコン） | 押したとき |
|---|---|---|
| 編集 | 新規作成（`IconPlusSquare`） | `board.newPlay()`（道具列の「新規」と同じ） |
| 編集 | 整列（`IconRotate`） | `board.resetPositions()` ＋ toast「フォーメーション位置を整列しました」 |
| 編集 | 相手を配置（赤い丸 `.oppdot`） | `board.addOpponent()`。相手が 0 のときだけ toast（道具列の「＋相手」と同じ） |

| アニメ | 描き込み（`IconShapes`、チェック＝`showDrawings`） | `setShowDrawings` の切り替え。OFF にするときは `setSelShape(null)`・`setSelStroke(null)`（道具列と同じ） |

| 編集 | 戦術アニメ（`IconFilm`） | `board.openStudio`（今のまま。**アニメ中は出さない**＝既に開いている） |
| 編集・アニメ | ライブラリ（`IconFolder`） | 今のまま |

- 処理は `FormationBar.tsx` の各ボタンの `onClick` と 1 か所にまとめる：`FormationBar.tsx` に `export function useBoardTools()`（または純関数 `boardToolItems(board)`）を作り、「新規・整列・相手・ハーフ・ルート表示・描き込み・残像」の `{ key, label, icon, onClick, checked? }` を返す。PC の道具列（`FormationBar` の JSX）はこの配列から描いてもよいが、**PC の DOM（クラス・順番・文言・title）は 1 文字も変えない**。簡単なのは JSX を今のままにして onClick の中身だけ共通の関数にすること。
- `MobileHeader.tsx` の `MobileHeaderMore` の `items` に任意の `checked?: boolean` を足す。`checked !== undefined` の項目は `role="menuitemcheckbox"`・`aria-checked`、右端にチェック（既存の `.colorchoice-check` の見た目を使う。`.mhead-more-item .colorchoice-check { margin-left: auto; margin-right: 6px; }` を基底に足す）。`checked` を渡さない既存の画面は今までどおり（`role="menuitem"`）。

- 項目を押すとメニューは閉じる（今の `MobileHeaderMore` の動き）。切り替え系も閉じてよい（結果はピッチで見える）。
- セットプレーデザイン（`isSp`）の項目（新規作成・戦術アニメ・ライブラリ）は変えない。選手（`coach` でない）はヘッダーに操作が無いので変わらない。
