### 1-2 保存（新しい鍵 `soccer_tactics_goals_v1`。オーナー決定 9・12）

`Record<playerId, PlayerGoals>`。

```ts
type GoalLevel = "long" | "mid" | "year" | "month" | "week";
interface Goal {
  id: string;
  level: GoalLevel;
  order: number;            // 同じ段の中の並び（今年の 3 つ、足した段の順）
  text: string;
  due?: string;             // YYYY-MM-DD
  period?: string;          // 今週＝その週の月曜（YYYY-MM-DD）、今月＝YYYY-MM
  ifThen?: string;          // 今週だけ
  status: "active" | "done" | "changed";   // 続けている・達成した・変えた（変えた物も消さずに残す）
  review?: "done" | "half" | "notyet";     // 週・月の見直しの結果（できた・半分・まだ）
  doneAt?: number;
  createdAt: number;
  updatedAt: number;
  updatedBy: string;        // "player" か "staff:名前"（プロフィールと同じ書き方）
}
interface GoalNote { id: string; goalId: string; text: string; by: string; ts: number }   // スタッフのひとこと
interface PlayerGoals {
  playerId: string;
  longLabel?: string;       // 大きな目標の段の表示名（無ければ学校区分の既定）
  goals: Goal[];
  staffNotes: GoalNote[];
  setupDone?: boolean;      // はじめての設定を終えたか
  setupStarted?: boolean;   // はじめての設定を「あとで書く」で途中にしたか（終えたら消す。判断 27）
  view?: "ladder" | "stairs";   // 目標の画面の見せ方（試作の切り替え。既定 ladder）
  updatedAt: number;
}
```

- 読み込みは壊れた形を捨てずに補う（配列が無ければ空）。保存は成否を返し、失敗したら「保存できませんでした（端末の保存容量がいっぱいです）」（プロフィールと同じ文）。
- 初期化（設定の「データ」）は今の仕組みのまま消える（鍵が `soccer_tactics_` で始まるため）。
- デモ：保存が空で、投入済みの印（`soccer_tactics_goals_seed_v1`）が無く、名簿に p08 がいるときだけ、佐藤 蒼空（p08）の目標を 1 回入れる（プロフィールのデモと同じ作法）。中身：大きな目標「サッカーの強い高校に合格する」（2028-03-31）、今年「A チームで全試合に先発する」（今の年度の 3/31）、今月「ファーストタッチを前向きに置く」、今週「受ける前に 2 回、首を振る」（もし「味方にボールが入ったら、首を振る」）、先週「逆足でトラップする」（見直し＝半分）。日付は今日から計算する。デモの今日の練習ノート（`BoardProvider.tsx` の `sampleNotebook` の `note_practice1`）の `goalPre` は「受ける前に右と左を見る」に変える（今月の目標と同じ文になるのを避ける。保存が空の端末に新しく入るデモだけ）。
- ノートに足す任意の項目（オーナー決定 6）：`NoteBase.goalId?: string`（そのノートの日が入る週の目標の id。提出のときに付ける）、`MatchNote.focus?: string`・`SoloNote.focus?: string`（今日意識したこと）。

### 2-1 はしご（`GoalLadder`。既定）

- 段の行：ラベル（12px・灰。「夢」「高校」「そのために」「今年」「今月」「今週」「今日」）と、右に期限（12px・灰。「2028 年 3 月」「11 月」「11/23〜11/29」「11/26（木）」）、その下に文（夢は 20px・700、ほかは 15px・700）。今年は 3 つまでを縦に並べる。
- 今週の段は青い 1px 枠の白いカードで開いている：文（17px・700）、「もし〜なら」1 行（12px・灰。あるときだけ）、月〜日の 7 つの丸（ノートを書いた日＝緑のベタ、今日＝青の輪、ほか＝灰の輪。下に曜日 12px）、今日のノートがあれば 1 行「今日意識したこと：… ・ 達成度 72%」、右下に「今週のノートを見る ›」（§2-5）。

- スタッフのひとことがある段は、文の下に 12px・灰で最新の 1 件（「岡本監督 ・ 11/26：…」）。
- 達成した目標：丸が緑のベタにチェック、その丸から次の段の丸までの縦線が緑（2px）、文の横に緑の札「達成」、12px・灰「11/20 に達成」。その下に「＋ 次の今月の目標を書く」のような 1 行（図 `gv1_ladder_done.png`）。

### 2-3 一覧（`GoalList`）と直すシート（`GoalEditSheet`）。PDF の GF2

- 一覧（図 `gf2_sheet.png` の後ろの画面）：上の帯の鉛筆で開く。設定のグループ化リストと同じ行（`SettingsRow` の形）を 1 枚の白いカードに並べる：1 行目にラベル（12px・灰。「夢」「高校」「今年」…）、2 行目に文（15px）、右に期限（12px・灰）と山形。成績の目標の行は 3 行目に 12px・灰「成績表の目標」（押すと成績表へ）。空の段は文の所に灰の文字「まだ書いていません」。今年は 3 つまでを 1 行ずつ。いちばん下に「＋ 今年の目標を足す」（3 つ未満のとき）と「＋ 段を足す」（足した段が 3 つ未満のとき）。行を押すと直すシート。
- はしご・階段の段を押しても、同じ直すシートが開く。

直すシートは今のプロフィールの編集と同じシート（`HubSheet`）。題名は「今週の目標」「今年の目標」のように段の名前。上から：目標（文）→ 期限 → 3 つの選択（今ある目標のときだけ）→「保存」（図 `gf2_sheet.png`）。段ごとに：

- 夢：文（複数行）。12px・灰「進路の『将来の目標』と同じものです」。保存すると進路の将来の目標が変わる。
- 大きな目標・足した段・今年・今月・今週：文（必須）、期限（大きな目標・足した段・今年は年と月を選ぶ。今月・今週は「11 月」「11/23〜11/29」と出すだけで直せない）、今週は「もし〜なら〜する（任意）」。大きな目標は「段の名前」（既定「高校」）も直せる。
- 今ある目標を開いたときは、期限の下に 3 つから選ぶ（今の `Seg`）：「続ける」（既定。文や期限の直しをそのまま保存）・「変える」（今の目標を「変えた」として残し、入れた文で新しい目標にする）・「達成した」（今の目標を「達成」にする。文の欄は「次の目標（任意）」になり、入れれば新しい目標も作る）。
- 今年は 3 つまで。シートは 1 つの目標ごとに開く。「＋ 今年の目標を足す」は 3 つ未満のときだけ。
- 新しい目標の期限の既定：大きな目標＝今の学校を卒業する年の 3 月（中2 の 11 月なら 2028 年 3 月）、今年＝今の年度の終わり、足した段＝1 年後の同じ月。
- 足した段と、今年の 2 つ目以降には「この目標を消す」（赤の文字。確認あり）。
- 今月・今週の欄の薄い例文は行動の形（「例）受ける前に首を振る」）。入れた文が「優勝」「勝つ」「合格」「選ばれる」で終わる・含むときは、欄の下に 12px・灰「そのために今週やることは？」を出す（保存は止めない）。

### 2-5 今週のノート（`WeekLog`）

- 図 `ng2_weeklog.png`。「今週のノートを見る ›」で、目標の画面の中の次の画面へ（題名「今週の目標」。戻るで はしご へ）。上に今月へのつながり（12px・灰）、今週の目標・期限・もし〜なら、月〜日の 7 つの丸。

## 3. はじめての設定（`GoalSetup`。PDF の GF1）

目標の画面の中の手順（4 歩。上の帯の題名は「目標を決める」）。上に進み具合の点 4 つ（済み＝青のベタ、今＝青の輪、先＝灰の輪）と「1 / 4」。各歩の上に、今までに書いた段が白いカードの小さな行で積み上がり（ラベル 12px・灰＋文 14px。1 行に収まらない文は「…」）、カードの下から問いへ短い縦の線でつなぐ（図 `gf1_dream.png`・`gf1_break.png`・`gf1_week.png`）。

1. 「いちばん大きな夢は？」（20px・700）補助文「期限は要りません。大きく書いてください」。文の欄（3 行）。見出し「例（押すと入ります）」と例の行（押すと欄に入る）：「プロサッカー選手になる」「日本代表でプレーする」「海外のクラブでプレーする」。進路の将来の目標が入っていれば、それが最初から入っている。
2. 「そのために、いつまでに何を？」大きな目標の文と期限（年と月）。例の行：「強い高校に合格する」「県トレセンに選ばれる」「J クラブのユースに入る」。その下に全幅の点線の行「＋ さらにそのために（段を足す）」（押すと、足した段の文と期限の欄が 1 組ずつ増える。3 つまで）。
3. 「今年と今月にやることは？」「今年のうちに（任意）」の文の欄 1 つと、「今月やること」の文の欄（補助文「〜する、の形で書く」）。
4. 「今週やることは？」補助文「〜する、の形で書く」。文の欄と「もし〜なら〜する（任意）」。ボタンは「決める」。

- 1 と 4 は必須、2 と 3 は「飛ばす」で先へ進める。どの歩にも「あとで書く」（灰の文字）：そこまでを保存して閉じ、目標の画面に「続きを書く」を出す。4 を終えたら `setupDone` を立てて、はしごを出す。
- 例の行は白地・1px 線・角丸 `--r-md`・全幅・各 44px 以上（縦に並べる）。ボタンは「次へ」（青の全幅）、その下に「あとで書く」（灰の文字）。
- 上の帯の「戻る」は 1 つ前の歩へ戻る（書きかけの欄はそのまま残る）。1 歩目の「戻る」で目標の画面へ出る。

## 4. どこからでも開く（`GoalOverlay`）と入口

- `GoalsProvider` が「目標の画面を開く／閉じる」を持ち、`GoalOverlay` を 1 つだけ置く（`ConsoleShell` の中）。開くと今の画面の上に重なる：スマホは下部タブの上までの全面（下部タブは見えたまま・今のタブが青のまま）、PC は中央のパネル（幅 520px・暗幕つき）。上の帯は題名「目標」と戻る。ほかのタブ・画面へ移ったら閉じる。作成中のノートのフォームの上で開いても、フォームの中身は消えない。同じタブの再タップと Esc でも閉じる（再タップは重ね表示を閉じるだけで、下の画面は動かさない。判断 36）。
- 入口：
  1. **ホームの目標カード**（`HomeGoals`。スマホと PC の両方。図 `gh_home_card.png`）：中身を「夢 → 今年 → 今週」の 3 行に作り直す（左に 1px の縦線と丸。夢は 15px・700、ほかは 14px。ラベル 12px・灰。今週の行の下に 7 つの丸）。今年が無ければ大きな目標を出す。カード全体を押すと目標の画面。右上に青の文字「目標を開く ›」。今週が無ければ今週の行は「今週の目標を決める」（青の文字）。何も無ければ「目標はまだありません。夢から今週までの目標を決められます。」＋ボタン「目標を決める」。今の 3 行（練習の目標・成績の目標・将来の目標）はやめる。
  2. **ノートの今週の目標の帯**（図 `ng1_practice.png`。`GoalBand`。練習・試合・自主練の作成フォームのいちばん上と、詳細の上）：白いカード 1 行（最小 52px）。左に的の線画（青）、12px・灰「今週の目標」（そのノートの日が今週でなければ「11/16〜11/22 の週の目標」）、14px・700 の文、右に山形。押すと目標の画面。その週の目標が無いときは「今週の目標を決める」（青の文字。押すと §2-4。今週でない日のノートでは帯を出さない）。詳細では、本人とスタッフにだけ出す（チームに共有されたノートをほかの選手が見るときは出さない）。
  3. **プロフィールの区画「目標」**（§5）。

## 6. ノートとのつなぎ（`NotebookScreen.tsx`）

- 練習ノートの作成：いちばん上（見出しと下書きの帯の下）に帯。「今日の目標（練習前）」の欄の名前を「今日意識したこと」に変える（保存の項目は今の `goalPre`）。薄い例文は、その週の目標があれば「例）（今週の目標の文）」、無ければ今の例文。案内の帯は「前回のひとこと：… ［今日意識したことにセット］」。案内の帯が出ているときは、薄い例文は今の例文のまま（今週の目標からは作らない。入口を 2 つにしない。PDF §8-4）。必須の知らせは「今日意識したことか振り返りを入力してください」。
- 試合ノート・自主練ノートの作成：いちばん上に帯。コンディションの下に任意の 1 行「今日意識したこと（任意）」（`focus`）。
- 提出・更新のたびに、そのノートの日が入る週の目標の `goalId` を付け直す（その週の目標が無ければ外す。判断 38）。
- 詳細：帯（§4 の 2）。練習の「今日の目標」の見出しを「今日意識したこと」に。試合・自主練は `focus` があれば同じ見出しで出す。
- ホームの目標カードから「練習の目標」の行が無くなるので、今日意識したことは目標の画面の今日の段と「今週のノート」で見る。
- 種類を選ぶシートの練習ノートの説明は「今日意識したことと振り返りを記録」。

## 9. 受け入れ基準（検証 `p46/b4/`）

1. はじめての起動（保存を空にしたデモ）で、佐藤 蒼空の目標の画面に 夢（進路の将来の目標の文）・高校・今年・今月・今週・今日 が上から並び、縦線が通り、今週が青い枠で開いている。
2. 夢の行を直すと、プロフィールの進路の「将来の目標」が同じ文に変わる（逆も同じ）。
3. 今週の目標を「変える」で直すと、新しい目標になり、前の目標は「変えた」として保存に残る。「達成した」で緑の丸と札になる。
4. 足した段：「＋ ここに段を足す」で 3 つまで足せ、4 つ目は足せない。消せる。
5. 週が替わったとき（検証では日付を 1 週進める）：今週の段に「今週の目標を決める」。押すと画面「今週の目標」に、先週の目標と 3 つのボタン、続ける｜変える。「決める」で今週の目標ができ、先週の目標に見直しの結果が残る。
6. はじめての設定：目標が空の選手で「目標を決める」→ 4 歩。1 と 4 だけ書いて終えられる。途中の「あとで書く」の後、「続きを書く」が出る。
7. 練習ノートの作成のいちばん上に帯。欄の名前が「今日意識したこと」。提出したノートに `goalId` が付く。目標の画面の「今週のノート」に、その日の今日意識したことと達成度が出る。
8. 試合・自主練の作成に帯と任意の「今日意識したこと」。保存データに `focus`。
9. ホームの目標カードが 夢 → 今年 → 今週 の 3 行（縦線と丸、7 つの丸）。押すと目標の画面が開き、スマホでは下部タブの「ホーム」が青のまま。PC では中央のパネル。
10. プロフィールのチップが 10 個で 5＋5 の 2 段（スマホ。「目標」は末尾）。「目標」を押すと目標の画面。上の帯の鉛筆で一覧が開き、行を押すと直すシート（目標 → 期限 → 続ける｜変える｜達成した → 保存）。
11. スタッフ：名簿 → 佐藤 蒼空 → 目標 で、白いカードの詰めたはしごが読め、直せない（鉛筆なし）。入力の薄い例文が「今週の目標にひとこと」。段を押すと薄い例文がその段の名前に変わる。送ると、選手の画面のその段の下に出る。「面談の記録を見る」で進路の区画へ移る。
12. 切り替え「階段」で紺の夢のカードと、右へ上がる階段になり、選び直すまで覚えている。
13. チームに共有された練習ノートをほかの選手で開いたとき、帯が出ない。
14. 古いデータ（目標の保存が無い・ノートに `goalId` が無い）で、どの画面もエラーにならない。今週の件数・連続・達成度の平均が変わらない。
15. スマホ 390×844 と PC 1440×1000 で横はみ出し 0、console error 0、`tsc` 0、`@media` 9。目標・ホームの目標カード・ノートの帯に関わらない画面は `b3` との画素差分 0。

1. **夢は進路の将来の目標そのもの**：写しを持つと 2 か所の文が食い違うため（PDF §8-6）。デモの夢は今の将来の目標の文（「プロを目指しつつ、大学でも続けられる学力をつける。」）のまま出る。

8. **「目標」のチップは末尾（10 個目）**：PDF の図（`gs_staff.png`）と §10-3 の 11 のとおり。今ある 9 個の並びを変えない。
