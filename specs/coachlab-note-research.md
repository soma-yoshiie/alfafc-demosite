# note（note.com）分析レポート — サッカー指導者向け記事投稿・販売機能の設計のために

調査日: 2026-09-11 / 出典は公式ヘルプ（help-note.com）を最優先。数値はすべて出典付き。確認できなかった点は「未確認」と明記。

## 1. 収益の仕組み

### 1-1. 収益メニューは5系統

| メニュー | 課金形態 | 開設条件 | プラットフォーム利用料 |
|---|---|---|---|
| 有料記事 | 単品買い切り | なし（初回のみ本人情報登録） | 10% |
| 有料マガジン | 記事束の買い切り | なし | 10% |
| 定期購読マガジン | 月額 | noteプレミアム（月500円）加入＋**運営事務局の審査**、月1回以上の更新義務 | **20%** |
| メンバーシップ | 月額（複数プラン可） | 無料＋**審査**、更新義務なし | 10% |
| チップ（サポート） | 任意額の投げ銭 | なし | 10% |

出典: [手数料](https://www.help-note.com/hc/ja/articles/360011358873) / [メンバーシップとは](https://www.help-note.com/hc/ja/articles/900000163906) / [定期購読マガジンとは](https://www.help-note.com/hc/ja/articles/360000390782) / [noteプレミアム](https://www.help-note.com/hc/ja/articles/360000279862) / [メンバーシップの審査](https://www.help-note.com/hc/ja/articles/13936447846297)

**設計上の要点**: 同じ「月額サブスク」でも、審査・更新義務・固定費のある定期購読マガジンが20%、後発で無料・義務なしのメンバーシップが10%。noteは明確にメンバーシップへ誘導しており、ヘルプ上も「おすすめ」と表記しています。加入期間中は過去記事も全部読める（メンバーシップ）／購読月に追加された有料記事しか読めない（定期購読マガジン）という**閲覧範囲の違い**が最大の構造差です（[出典](https://www.help-note.com/hc/ja/articles/360011359073)）。

### 1-2. クリエイターの取り分（2段階＋固定費）

**① 事務手数料（＝決済手数料。読者が選んだ決済手段で決まる。クリエイター側では選べない）**

| 決済手段 | 率 |
|---|---|
| クレジットカード | 5% |
| 携帯キャリア決済 | **15%** |
| PayPay | 7% |
| Amazon Pay | 7% |
| noteポイント | 10% |
| PayPal | 6.5% |

**② プラットフォーム利用料** = (売上 − 事務手数料) × 10%（定期購読マガジンのみ20%）
**③ 振込手数料** = **270円**（振込1回につき1回のみ）

公式の計算例: 1,000円の有料記事をクレカ購入 → 事務手数料50円＋利用料95円＋振込手数料270円 → **手取り585円（58.5%）**。4件まとめて振込申請すると4,000円→3,042円（76%）。
出典: [コンテンツを販売する際に引かれる手数料](https://www.help-note.com/hc/ja/articles/360011358873)

→ **少額×都度振込は手数料負けする設計**。手取り率は「決済手段」と「振込頻度」で15%〜25%も変動します。

### 1-3. 価格の下限・上限

- 記事／マガジン／メンバーシップ: **100円〜50,000円**、noteプレミアム・note pro会員は上限**100,000円**
- チップ（サポート）: **100円〜100,000円**
- キャリア決済の上限: ドコモ／au 1回10,000円、ソフトバンク1回100,000円。定期課金は月合計10,000円まで

出典: [価格の設定とお支払い方法について](https://www.help-note.com/hc/ja/articles/360011270114) / [チップ機能とは](https://www.help-note.com/hc/ja/articles/360011359673)

### 1-4. 売上の受け取り

- **売上確定日は毎月2日**（返金機能導入に伴い1日から変更）
- 前月末までの未振込合計が**1,000円以上**で振込申請可能
- 2〜20日申請 → **当月末（最終営業日）**振込／21日〜翌1日申請 → 翌月末振込
- 申請後、振込完了までは次の申請不可。**申請の取り消しは不可**
- 2024/12/24から**自動振込申請**あり（毎月6日までにONで7日に自動申請）
- **預かり期限180日**。期限切れ・1,000円未満は**Amazonギフトカード**で払い出し（振込手数料はかからないが事務手数料・利用料は引かれる）。ギフトカード上限超＋口座未登録のまま期限を過ぎると**失効**
- 退会すると未申請の売上は申請不可

出典: [売上金を受け取る](https://www.help-note.com/hc/ja/articles/360010430873) / [売上金について](https://www.help-note.com/hc/ja/articles/360011270774) / [自動振込申請機能](https://www.help-note.com/hc/ja/articles/41319633623193) / [預かり期限が過ぎた売上金](https://www.help-note.com/hc/ja/articles/900003987706)

### 1-5. 未成年・法人の扱い

- **18歳未満**が有料記事を投稿する／メンバーシップを運営するには、**保護者の同意フォーム＋保護者の本人確認書類**（マイナンバー記載なし・裏面含む）が必須。審査は数日〜数週間。同意のない未成年申請はメンバーシップ審査の代表的な見送り事例
- 初めて有料記事を公開する全員に**「本人情報の登録」**（非公開・本人確認目的のみ）
- 法人／個人は設定のスイッチで後から切替可能。法人向け上位プランは note pro（月80,000円／年880,000円・税抜）

出典: [未成年者の有料記事投稿](https://www.help-note.com/hc/ja/articles/900000359563) / [未成年者のメンバーシップ運営](https://www.help-note.com/hc/ja/articles/900003105023) / [本人情報の登録](https://www.help-note.com/hc/ja/articles/30821598802713) / [個人/法人の切替](https://www.help-note.com/hc/ja/articles/42962413734681) / [note proの基本料金](https://www.help-note.com/hc/ja/articles/900000576123)

## 2. 有料記事の見せ方（ペイウォール）

### 2-1. 有料ラインの自由度

有料ラインは**段落と段落の境界であればどこにでも置け**、編集画面に挿入される「ここから先は有料部分です」パーツを**ドラッグして移動**できます。段落境界以外には置けないため、置きたい位置の前後に段落を作る必要があります。公開設定画面（有料エリア設定）と本文編集画面の両方から設定可能。自分でログイン中は購入導線が出ないため、ログアウト／シークレットモードで確認する運用が案内されています。
出典: [有料記事を書く（有料ラインの設定）](https://www.help-note.com/hc/ja/articles/360008882894)

有料マガジン／定期購読マガジンの収録記事には別途**「試し読みエリア」**を設定でき、ライン上は誰でも読める形になります（[出典](https://www.help-note.com/hc/ja/articles/900004730643)）。

### 2-2. 購入前に見えている情報

公式ヘルプと [note公開API](https://note.com/api/v3/notes/na931b48827c3) のレスポンスから確認できる、購入前に提示される要素:

- 価格、決済手段の選択肢、**「返金可」／「返金不可」**のラベル
- **有料エリアの残量**（`remained_char_num` 残り文字数、`remained_image_num` 画像数、`remained_file_num` ファイル数、`remained_sound_num` 音声数）
- スキ数、コメント数、ハッシュタグ、見出し画像、無料部分の本文、目次
- 数量限定販売の残数、タイムセール／先行販売の状態
- 販売管理画面には**購入者数・残数量**が桁省略なしで表示（一方、クリエイターページ上のスキ数・フォロワー数・記事数は「1.0万」形式に丸められる）

出典: [note内の数値の表示について](https://www.help-note.com/hc/ja/articles/60065014108313) / [有料記事を購入する](https://www.help-note.com/hc/ja/articles/360010310214)

### 2-3. 購入後・価格変更・返金

- 購入者は**常に最新版**を閲覧（過去バージョンを見る手段はない）。値上げ・値下げがあっても**差額の請求も返金もなし**
- 有料記事は一度販売すると**下書きに戻せない**。削除しても購入者は「購入した記事」から閲覧可能（＝購入者保護）
- **返金は有料記事のみ・購入後24時間以内**。クリエイターが記事単位で受付ON/OFF（既定はON）。noteが濫用防止の審査を行い、必ず返金されるわけではない
- **返金対象外**: 有料マガジン、定期購読マガジン、チップ、メンバーシップ、ゲスト購入（会員登録なし購入）、noteプレミアム
- 定期購読マガジンは**価格変更不可**（別マガジンとして再申請が必要）
- 月額課金は**日割りなし**

出典: [購入者が見るのは最新版](https://www.help-note.com/hc/ja/articles/48546952378393) / [値上げ前購入者](https://www.help-note.com/hc/ja/articles/42692345441689) / [下書きに戻せますか](https://www.help-note.com/hc/ja/articles/360011270874) / [返金ルール](https://www.help-note.com/hc/ja/articles/360000670602) / [返金の設定方法](https://www.help-note.com/hc/ja/articles/360000670622) / [定期購読の価格変更](https://www.help-note.com/hc/ja/articles/43701793696281) / [日割り](https://www.help-note.com/hc/ja/articles/34866497130649)

### 2-4. 販促の仕掛け（プレミアム／pro限定）

- **数量限定販売**: 1〜10,000部
- **タイムセール**: テキスト有料記事のみ。**最大90%引き（最低100円）〜定価未満**。景表法対応として**前回終了から2週間は再実施不可**、期間中の延長不可、数量限定・SNSプロモーションとの併用不可

出典: [noteプレミアム会員でできること](https://www.help-note.com/hc/ja/articles/360000279862) / [タイムセール機能FAQ](https://www.help-note.com/hc/ja/articles/42430578897817)

## 3. クリエイター（投稿者）のプロフィール

**表示される項目**: プロフィールアイコン／ヘッダー画像／クリエイター名／プロフィール文（**140文字以内**を推奨）／ソーシャルリンク（X・Facebook・YouTube・Instagram・LINE・TikTok）／フォロー数・フォロワー数／記事数／固定記事／お知らせ枠／ウィジェット（プレミアム、最大5つ）。

**タブ構成**: ホーム／記事／マガジン／メンバーシップ／スキ／月別、加えて「プロフィール」「仕事依頼」。後者2つは**独立した入力欄ではなく、投稿済み記事を「プロフィールとして表示」「仕事依頼として表示」に指定する方式**です。

→ **経歴・資格・保有ライセンスのような構造化フィールドは存在しません**。自己紹介記事という自由テキストで代替する設計です。これは指導者向けサービスにとって最も大きな欠落です。

**認証バッジ**: 緑のチェックマーク。noteが企業・著名人のページを「公式である」と認証するもので、すべての企業・著名人に付くわけではない。note pro契約アカウントは事務局審査を経て付与され、**定期的な見直しで非表示になることがある**。申請はアカウント設定→運営サポート→プラン設定から。

**バッジ**: 「note IDを登録した」「初めて記事を投稿した」など行動に応じて付与される実績バッジ（ダッシュボードで金／グレー表示）。メンバーシップには**在籍期間に応じたバッジ**をオーナーが付与する仕組みもあります。

出典: [クリエイターページ画面の名称と機能](https://www.help-note.com/hc/ja/articles/900003786026) / [プロフィール欄で自己紹介をする](https://www.help-note.com/hc/ja/articles/29243678822681) / [SNSのURLを表示する](https://www.help-note.com/hc/ja/articles/21254054807193) / [プロフィール・仕事依頼タブ](https://www.help-note.com/hc/ja/articles/48512771608089) / [認証マークについて](https://www.help-note.com/hc/ja/articles/360000391102) / [note pro認証マークの申請](https://www.help-note.com/hc/ja/articles/8118454302745) / [バッジを取得する](https://www.help-note.com/hc/ja/articles/900006176946) / [活動期間バッジ](https://www.help-note.com/hc/ja/articles/22753549697817)

## 4. フォロー・通知・発見

**フォローと通知**: フォロー時の既定は**「まとめて通知」**。個別に**「すぐに通知」**へ切り替えると、そのクリエイターの新規投稿ごとにベル通知・プッシュ通知が届きます（iOS/Androidアプリ。Webプッシュは非対応）。通知対象は**新規投稿のみで、記事の更新や再公開は通知されません**。両方を解除するにはフォロー解除しかない、という割り切った設計です。
出典: [クリエイターごとの通知機能](https://www.help-note.com/hc/ja/articles/22739618193561) / [「すぐに通知」と「まとめて通知」](https://www.help-note.com/hc/ja/articles/50894897650457) / [フォローする/外す](https://www.help-note.com/hc/ja/articles/360010308794)

**検索**: 検索対象は**ハッシュタグ／クリエイター名（ニックネーム）／note ID／プロフィール文／本文キーワード**。結果は**記事・マガジン・クリエイター**に分かれ、並び替えは**「人気」「急上昇」「新着」**。クリエイター単位の絞り込みは `from:@noteID キーワード` の構文。
出典: [キーワード、ハッシュタグ、クリエイターを検索する](https://www.help-note.com/hc/ja/articles/360010417153)

**ランキングのロジック**: 「人気」「急上昇」「新着」の判定基準は**不正防止のため非公開**と明言されています（[出典](https://www.help-note.com/hc/ja/articles/4403256523289)）。

**おすすめのロジック（唯一の公表情報）**: 2026年1月21日、note CXO 深津貴之氏が「推しアルゴリズム」の方針を公開。優先順位は ①人間による生の一次情報・体験の記録・作品 → ②一次情報をAIをツールとして編集したもの → ③ユニークなAI自動生成 → ④新規性のない大量生成。積極的に推すのは実体験・失敗談・ケーススタディ・一次創作・業界の入門コンテンツなど。重視軸は**「一次性・独自性・検証可能性」**。
出典: [noteの推しアルゴリズムについて（深津貴之）](https://note.com/fladdict/n/n5b78bb223b35)

**ハッシュタグ**: 公開時に設定する検索キーワード。タグ一覧ページに集約される。推奨は**3〜5個**。**複数タグのAND検索は非対応**（2025年1月28日時点）。カテゴリという別軸は読者側には提供されず、実質タグが唯一の分類軸です。
出典: [ハッシュタグとは](https://www.help-note.com/hc/ja/articles/900004261886) / [ハッシュタグのAnd検索](https://www.help-note.com/hc/ja/articles/42856303061785)

ホーム画面のトピックは、読者側で**非表示・通報**が可能（[出典](https://www.help-note.com/hc/ja/articles/9510944410905)）。

## 5. 記事の編集機能

- **見出し**: 大見出し／小見出しの2階層のみ
- **目次**: 見出しを設定した上で「＋」から目次パーツを任意位置に挿入。目次項目は見出しへアンカーリンク。**テキスト記事限定**、プレビューでは表示されない
- **画像・埋め込み**: URLを貼るだけでカード化。動画・音楽・音声・SNS・デザイン・フォーム・マップ・イベント・求人など多カテゴリの公式埋め込みに対応。埋め込みには noteクローラー（UA: `notebot`）がアクセスできる必要があり、新規サービスは「embed機能 開発ガイドライン」からの申請制（個人開発者は不可）
- **下書き**: 保存可。**下書き共有用リンク**で公開前レビューが可能
- **予約投稿**: **noteプレミアム／note pro限定・Webブラウザのみ**（アプリ不可）。同時刻の複数予約は記事の作成順に公開
- **再編集**: 公開後も自由。購入者には常に最新版が表示。ただし有料記事は下書きに戻せない
- **シリーズ化**: マガジンが担当。**無料／有料／定期購読／共同運営**の4種。記事の追加数に**制限なし**、並べ替え・先頭固定が可能。他人の記事も無料マガジンには追加できる（有料マガジンは不可）
- **ダッシュボード**: インプレッション／ページビュー／スキ／コメント／売上の5指標。期間は過去7日・28日・365日・全期間・今月・先月・カスタム。記事／メンバーシップ／マガジン別の内訳、流入元も確認可能

出典: [記事に目次を表示させる](https://www.help-note.com/hc/ja/articles/360017021253) / [埋め込みできるサービス一覧](https://www.help-note.com/hc/ja/articles/360019596133) / [下書きの共有](https://www.help-note.com/hc/ja/articles/360018997193) / [noteプレミアム会員でできること](https://www.help-note.com/hc/ja/articles/360000279862) / [マガジンとは](https://www.help-note.com/hc/ja/articles/360000383501) / [マガジンの記事数](https://www.help-note.com/hc/ja/articles/360011271154) / [ダッシュボードで各指標とグラフをみる](https://www.help-note.com/hc/ja/articles/61982979089305)

## 6. 信頼・安全

**スキ**: タイムライン上・記事ページ上のどちらからも付与でき、再タップで取り消し可能。クリエイターは**スキのお礼メッセージ**を設定できます。記事詳細では桁省略なし、一覧では丸め表示。

**コメント**: 2025年9月8日以降に公開された記事は**スレッド形式・個別返信に対応**（アプリはv9.17以上が必要）。コメント欄のON/OFFはnoteプレミアム限定機能。

**ブロック**: フォローが自動解除され、相手はスキ・コメント・マガジン追加・**有料記事や定期購読の新規購入・メンバーシップ入会ができなくなる**。定期購読中の読者をブロックすると購読は強制停止。メンバーシップ参加者はブロックしても在籍は続くため、別途退会処理が必要。

**通報**: クリエイター／個別記事／マガジン／ホームトピック単位で「報告する」→理由選択＋詳細入力。**原則として返信はなし**。

**ガイドライン（禁止コンテンツと専門的助言の扱い）**: コミュニティガイドラインは、著作権・肖像権・プライバシー侵害、なりすまし、差別（民族・宗教・人種・性別・年齢）、自殺・自傷の賛美、薬物、アダルト・暴力表現、詐欺、**マルチ商法等の情報商材**、**「必ずもうかる」等の著しい誤解を招く表現**、そして**景品表示法・薬機法・医療法その他の広告関連法令に違反するもの、またはそのおそれのあるもの**を禁止。最上級・No.1表示にも個別ルールがあります。健康・医療・栄養といった**専門的助言に近い領域は「法令違反のおそれ」で包括的に規制する方式**で、資格確認のような仕組みは設けていません。

## 8. 自社（サッカー指導者向け・クラブ運営アプリ内）への示唆

**真似すべき仕組み**

1. **有料ラインの位置を段落単位で自由に動かせる方式**。「無料部分＝課題提起と結論の一部／有料部分＝具体的なメニューと図」という指導者コンテンツの構造にそのまま合う。加えて**残り文字数・画像数・動画数の事前開示**は、購入判断材料として費用対効果が極めて高い（実装コスト小・信頼効果大）。
2. **サブスクは「加入期間中は過去記事も全部読める」型に一本化**。noteの定期購読マガジン（購読月の記事しか読めない）は指導者向けに致命的に相性が悪い。過去のトレーニングメニュー資産にアクセスできることが継続動機そのものになる。
3. **返金を「24時間以内・売り手が記事単位でON/OFF・運営が審査」**の三点セットで運用し、売上確定日を返金期間の後ろに置く。購入者保護と売上の確定性を両立できる。
4. **販売実績のある記事は削除しても購入者が読み続けられる**保証と、**購入者には常に最新版を配信**する仕様。指導メソッドは更新されるので、「買ったら更新分も読める」は指導者向けでは強い訴求になる。

**避けるべき点**

5. **決済手段によって手取りが5%〜15%変わる転嫁モデル**。指導者は手取りが読めないと値付けができない。**手数料は単一率で提示**し、決済手段差は自社で吸収する。
6. **少額×都度振込で手数料負けする設計**（270円固定＋1,000円下限＋180日の預かり期限＋失効リスク）。**自動振込を既定ON**、下限を下げる、期限切れ失効は設けない、のいずれかで回避する。
7. **ランキング基準を完全非公開にすること**。noteは不正防止を理由に非公開だが、母数の小さい指導者コミュニティでは「なぜ自分の記事が出ないのか」への不信に直結する。**評価軸（更新頻度・完読率・タグ適合など）は公開し、重みだけ非公開**にするのが現実的。
8. **経歴・資格の構造化フィールドを持たないこと**。noteは自己紹介記事という自由テキストで代替しているが、**指導者にとって保有ライセンス（S/A/B/C級、キッズリーダー）・指導年代・所属クラブ・実績は購入判断の中核**。これを自由記述に落とすのは最大の機会損失。
9. **タグのAND検索非対応**。「#U-12 かつ #セットプレー」が引けないのは指導者の検索行動と致命的に噛み合わない。**年代×局面×テーマの多軸フィルタ**を最初から設計する。

**差別化の余地**

10. **「ライセンス・指導年代・所属」の運営認証バッジ**を、note の認証マーク（企業・著名人向け、pro契約前提、定期見直しで剥奪あり）の思想だけ借りて、**個人指導者向けに開放**する。これに加えて、note が持たない **クラブ運営アプリ固有の文脈**——自クラブのコーチだけに配る限定公開、練習メニューとして記事を練習日程に紐づける、保護者向け／指導者向けの読者セグメント分け——を組み合わせれば、汎用プラットフォームには構造的に真似できない領域になる。専門的助言の扱いは、note のように「法令違反のおそれ」で包括規制するのではなく、**医療・栄養・フィジカル領域は認証済み資格保有者のみ販売可**とする方が、指導者向けサービスとしては信頼を積める。
