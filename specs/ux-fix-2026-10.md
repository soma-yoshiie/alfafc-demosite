## R1 — 数字と状態・バッジ・文言・細部

### R1-1 出欠の約束（t1）

**決定：選手・保護者が自分の出欠を答えられるようにする。** 言葉は「出席・欠席・未定・未回答」の 4 つ（スタッフ側の「未記録」は「未回答」に統一）。

- データは今の `TeamData.attendance[eventId][playerId] = { status, comment }`（`team.setAttendance`）をそのまま使う。選手は自分の id だけ書ける。
- **予定の詳細**（`TeamHub.tsx` の `eventView` シート／PC ペイン）：選手・保護者（`!isCoach` で `me` がいる）のときは、日時のブロックの直下に「自分の出欠」の区画：3 択の切り替え（出席／欠席／未定。`.mseg-item` と同じ見た目の全幅 3 分割、選択中は `--accent-tint`＋`--accent`）＋ 任意の一言（`input`。placeholder「例）塾のため 30 分遅れます」）。押した時点で保存（`team.setAttendance(eventId, me, status, comment)`）、トースト「出欠を送りました」。過去の予定（終了日 < 今日）には出さず、「出席で回答済み」のように文字だけ。
- **スマホの日別シート**（カレンダーの日付を押したときの一覧）：選手のときは各予定の行に「出席／欠席」の 2 ボタン（44px）＋ 回答済みは状態の文字（「出席で回答済み」）。カード全体を押すと詳細へ（「詳細 ›」の文字は外す）。
- **ホームのヒーロー**（`HomeMenu.tsx:396`／`MobileHome.tsx:376`）：未回答なら「出欠を回答する」（今の白いボタン）、回答済みなら「出欠を変更する」（白い枠だけの控えめな見た目 `.mdb-cta.ghost`）。`metaValue` は「出席」「欠席」「未定」「未回答」。
- **スタッフ**：ホームの「未回答 N 名」と予定の詳細の内訳（出席 N・未定 N・欠席 N・未回答 N）は同じ数（`team.summary(eventId)` の `none` を「未回答」と呼ぶ）。`TeamHub.tsx` の「未記録」の文字（1489／2948／3873／4870 行付近、`STATUS` のラベル）を「未回答」に。出欠の記録シート（`AttendanceRecordBody`）の見出しも同じ。
- カレンダーの予定チップ（選手）：未回答の予定には小さな点（`.calev-dot`。`--accent`）を付ける。リスト表示の選手側に「未回答だけ」のトグル（`.calfilter-toggle` と同じ）を足す。

### R1-2 「開催中」と残り時間（t1・t10）

- `lib/calendarUtils.ts` の `isOngoing(e, today)` を時刻で判定する関数 `eventPhase(e, now: Date): "before" | "ongoing" | "after"` に替える（既存の呼び出しは `eventPhase(e, new Date()) === "ongoing"` に）。開始＝`date`＋`time`（無ければ 0:00）、終了＝`endDate`＋`endTime`（無ければ `time` があれば開始＋2 時間、終日なら 23:59）。
- カウントダウン（`homeData.tsx` の `useCountdown` を使う `HomeMenu.tsx:296`／`MobileHome` の同じ所）：表示は 1 本の関数 `fmtCountdown(cd)`：開始済み＝「開催中」（終了後は次の予定に移るので出ない）、1 日以上＝「あと N 日」、1 時間以上＝「あと N 時間」、1 時間未満＝「あと N 分」。「0日」「0時間」は出ない。
- 題名に種類の名前が含まれるとき（例「全体練習」に「練習」）は、ヒーローの種類チップを出さない。

## R2 — 1 画面目の主役と次の一手

### R2-1 選手のノートのホーム（t2・t6）
