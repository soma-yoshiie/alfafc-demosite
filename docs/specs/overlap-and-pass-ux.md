# 実装指示書 Round A: 場面の重ね（ワンツー対応）＋パスUX改善

作成: PM（2026-07-09）／ユーザー承認済み

## A1. 詳細タイミングで場面を重ねられるように（ワンツー対応）

### 仕様
`Move.start`（場面内オフセット）に**負の値**を許可する。負のオフセット＝「前の場面がまだ再生中のうちに動き出す」。再生は `absStart` の絶対時刻ソートなので追加の再生ロジックは不要（要確認テストのみ）。

### 変更
- `components/TacticsTimeline.tsx`:
  - バー移動（mode==="move"）の下限クランプを `d.stepBase` から **`d.stepBase - 前場面の長さ`**（`step === 0` のときは従来どおり 0）に変更。`前場面の長さ = stepDur(moves, step - 1)`（onBarDown 時に計算して DragState に保持）
  - スナップ候補は現状のまま（全 move の絶対開始/終了 + 場面頭）で機能する
  - tlhint の文言に「バーを前の場面へ食い込ませると動きを重ねられます（ワンツー等）」の趣旨を追記（1行で簡潔に）
- `lib/animation.ts`:
  - `stepDur` は現状 `let d = 0` 初期のため負にならないことを確認（変更不要のはず。コメントで「負の start を許容し、末尾オフセット基準」の旨を明記）
  - `stepStartTime` / `stepAtTime` / `animTotal` は名目境界のまま（変更不要）
- `components/BoardProvider.tsx`: `UPDATE_MOVE` はパッチ適用のみなので変更不要（確認のみ）
- 場面単体再生（playStep）は名目区間（stepStartTime から）で従来どおり＝食い込んだ冒頭部分は「通し」または前場面の再生で確認する仕様（変更しない）

### 受け入れ条件
- [ ] 場面2のバーを場面1の時間帯まで左ドラッグでき、通し再生で場面1の動きと場面2の動きが重なって再生される（ワンツー: A走る(場面1)→走っている最中にBのリターンパス(場面2)が出る）
- [ ] 場面1（先頭）のバーは従来どおり 0 が下限
- [ ] タイムラインのバー表示・スナップ・ドラッグ確定が負オフセットでも正しい
- [ ] 保存/共有/GIF/WebM で重なりが再現される

## A2. アニメ中に「ボールを味方へドラッグ＆ドロップ＝パス」

### 仕様
アニメモード（ルートツール）でボールをドラッグして**味方（pid のある slot）のディスク上で離した**とき、手描きルートではなく**パスを自動生成**する（R2 の `passTo` と同じ結果）。

### 変更
- `components/usePointerDrag.ts` の anim モード・`actor === "ball"`・ドラッグ確定の分岐:
  1. ドロップ位置が味方ディスクから 40px 以内（編集モードの `overlappingBallTarget` と同じ判定。ただし**相手は対象外・味方のみ**）かを判定
  2. 該当し、かつ「その場面の保持者が存在する」（`board.holderAtStep(activeStep) ?? board.holderAtStepEnd(activeStep)` が非null）かつ受け手がその保持者自身でない場合 → tempDraw を破棄して `board.passTo(受け手)` を呼ぶ（ルートは追加しない）
  3. それ以外（保持者なし／ドロップ先が味方でない）→ 従来どおり手描きルートとして確定
- `components/BoardProvider.tsx` の `passTo`: 現在 `selActorRef` から出し手を特定している場合、**出し手を「その場面の保持者（holderAtStep ?? holderAtStepEnd）」から特定する形に変更**（selActor に依存しない。タップ経由でも同じ保持者が出し手なので挙動互換）。ボールD&D経由でも正しく動くことが目的
- ガード（人数・場面自動追加 ensureBallStep 等）は既存のまま活かす

### 受け入れ条件
- [ ] 保持者がいる状態で、アニメ中にボールを味方へドラッグ→ドロップするとパスが生成される（タップ方式と同一結果・自動場面追加も同様に機能）
- [ ] 保持者がいない場合・味方以外へのドロップは従来どおり手描きルート
- [ ] ボールの「移動」ツール（translate）は無変更

## A3. 保持中の常設ヒントバー

### 仕様
アニメモードで**選択中のアクターがその場面の保持者**（`selActor === holderAtStep(activeStep) || selActor === holderAtStepEnd(activeStep)`）のとき、ピッチ上部中央に常設の操作ガイドを表示する。

### 変更
- `components/Pitch.tsx`（または専用の小コンポーネント）: `.holdguide` div を `.pitch` 内上部中央に表示。文言: 「味方をタップ＝パス ／ ゴールをタップ＝シュート ／ ボールを味方へドラッグでもパス」。pointer-events: none。トークンより上の z-index（8程度）。ダークピル（`.fphint` と同系の見た目）
- 既存の「1セッション1回のヒントtoast」（holderHintShown）は**削除**（常設バーに置き換え）
- `app/globals.css`: `.holdguide` のスタイル追加（小さめフォント・半透明ダーク背景・角丸・中央上部 absolute）

### 受け入れ条件
- [ ] 保持者を選択している間だけガイドが表示され、選択解除・非保持者選択・編集モードでは消える
- [ ] 再生中も表示されて邪魔にならない（ピッチ上端・小サイズ）
